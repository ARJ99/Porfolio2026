## 💻 Installation

To get a local copy up and running, follow these simple steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/ARJ99/Porfolio2026.git
    cd Porfolio2026
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    # or
    yarn install
    ```

3.  **Set up environment variables (for EmailJS):**
    Create a `.env` file in the root directory and add your EmailJS credentials:
    ```env
    VITE_EMAILJS_SERVICE_ID=YOUR_SERVICE_ID
    VITE_EMAILJS_TEMPLATE_ID=YOUR_TEMPLATE_ID
    VITE_EMAILJS_PUBLIC_KEY=YOUR_PUBLIC_KEY
    ```
    *You can obtain these from your EmailJS account.* 

4.  **Run the development server:**
    ```bash
    npm run dev
    # or
    yarn dev
    ```

This will start the development server, and you can access the portfolio at `http://localhost:5173` (or the port specified by Vite).

## 🚀 Usage

This project is a personal portfolio website designed to showcase projects, skills, and experience. Here's how you can use and interact with it:

*   **Navigation:** Use the navigation bar at the top to jump to different sections like About, Projects, Experience, and Contact.
*   **Project Exploration:** Visit the 'Projects' section to view detailed information about past work, including descriptions, technologies used, and links to live demos or GitHub repositories.
*   **Contact Me:** Use the 'Contact' form to send a message directly. The form is integrated with EmailJS for seamless message delivery.
*   **Download CV:** Find a 'Download CV' button, typically in the hero section, to get a copy of the resume.
*   **Social Links:** Connect via the social media links provided in the header and footer (GitHub, LinkedIn).
